# Contributing to GerChain

## Contribution boundary

GerChain CORE is a protected infrastructure codebase. Public, unsolicited source-code contributions are not accepted at this time.

Changes to CORE are accepted only through controlled maintainer review and the repository's protected-branch governance.

## Required process for authorized contributors

1. Open or reference the relevant change request.
2. Keep changes narrowly scoped and traceable.
3. Do not commit secrets, credentials, private keys, personal data, production configuration, or confidential commercial/IP material.
4. Add or update automated tests when behavior changes.
5. Provide security and migration impact information where applicable.
6. Obtain the required independent review before protected-branch merge.

## CORE assurance boundary

The current CORE assurance scope covers the GerChain technical infrastructure. SHUUD application behavior is outside CORE assurance scope unless explicitly included in a future assessment.

## Intellectual property

GerChain CORE, NEF, G-3 methodology, proprietary algorithms, architecture, know-how, and related intellectual property remain subject to the project's controlled IP policy. This document does not grant any license or ownership right.

## Security

Do not disclose suspected vulnerabilities through public issues. Follow `SECURITY.md` for private security reporting.

## Assurance status

Repository security controls are being aligned with the OpenSSF OSPS Baseline and MNS ISO/IEC 27001:2023 readiness program. This document does not constitute certification or independent audit attestation.
