# NEF–G-3–GerChain — Personnel Security Requirements

**Status:** Controlled requirements — evidence pending

## 1. Lifecycle

Personnel security shall address, as applicable:

`Before engagement → During engagement → Role change → Termination`

## 2. Required controls and evidence

The organization shall define and retain evidence for:

- confidentiality obligations;
- security responsibilities;
- role-based access;
- security awareness/training;
- acceptable-use requirements;
- reporting obligations;
- access changes following role changes;
- timely access removal at termination;
- return of organizational information/assets;
- disciplinary process where applicable.

Where screening is used, it shall be lawful, risk-based and appropriate to the role.

## 3. Evidence

Evidence may include signed agreements, training records, role/access approvals, joiner/mover/leaver records, offboarding checklists and periodic review records.

Personal information shall be minimized and protected; this repository document must not contain personnel secrets or unnecessary personal data.
