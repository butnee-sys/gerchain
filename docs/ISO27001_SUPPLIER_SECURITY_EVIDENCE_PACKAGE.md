# NEF–G-3–GerChain — Supplier Security Evidence Package

**Status:** Evidence template — organizational completion required
**Branch:** `docs/iso27001-alignment`

## 1. Objective

Demonstrate that external suppliers and service providers affecting the ISMS scope are identified, assessed, contractually governed and reviewed according to information-security risk.

## 2. Required evidence

### Supplier register
- supplier name/service;
- service owner;
- information/system access;
- data classification;
- criticality;
- geographic/hosting boundary;
- contract reference;
- security review date;
- current status.

### Due diligence
- security assessment;
- relevant certifications/assurance;
- access/data review;
- continuity assessment;
- incident-notification capability;
- risk acceptance where gaps remain.

### Contract controls
- confidentiality;
- information-security requirements;
- data handling;
- access limitation;
- incident notification;
- subcontractor requirements;
- continuity/exit;
- evidence/audit rights where applicable.

### Offboarding
- access removal;
- data return/deletion;
- credential/key revocation;
- asset return;
- final review.

## 3. Acceptance test

Move from **MISSING** to **AVAILABLE** only after the supplier population is identified, material suppliers are assessed and objective contract/review evidence is retained.

## 4. Evidence protection

Supplier contracts may contain confidential commercial information. Store controlled copies outside this repository where appropriate and record only traceable references here.
