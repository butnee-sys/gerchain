# DEETI Falsification Matrix v1

**Status:** Research control document
**Date:** 2026-09-17

| Claim | Prediction | Falsification test | Failure criterion |
|---|---|---|---|
| ET is foundational | Higher ETI improves primary DE outcome | Regression / controlled comparison | Effect ≈ 0 or opposite |
| Trust is necessary | Removing T degrades outcome | Component ablation | No material degradation |
| Transparency is necessary | Removing Tr degrades outcome | Component ablation | No material degradation |
| Verified fulfilment is necessary | Removing Tf degrades outcome | Component ablation | No material degradation |
| ET components are complementary | Joint model outperforms additive-only model | Interaction test / model comparison | No meaningful interaction |
| ET is not merely correlated with system maturity | ET effect survives maturity controls | Controlled regression / matching | Effect disappears |
| ET generalizes | Effect replicates across domains | Cross-domain replication | Effect domain-specific only |
| ET is robust | Effect survives measurement alternatives | Sensitivity analysis | Effect specification-fragile |
| ET has practical value | Effect exceeds pre-specified practical threshold | Effect-size analysis | Statistically significant but practically trivial |
| ET has causal relevance | Intervention changes outcome | Quasi-experiment / experiment | No intervention effect |

## Decision rule

```text
If primary falsification criteria fail:
    foundational claim = NOT SUPPORTED

If evidence is mixed:
    foundational claim = INCONCLUSIVE

Only after independent replication and robustness:
    foundational claim = EMPIRICALLY SUPPORTED
```

No result from this matrix alone constitutes universal proof.
