# NEF–G-3–GerChain — Physical Security Evidence Package

**Status:** Evidence template — site-specific completion required
**Branch:** `docs/iso27001-alignment`

## 1. Objective

Demonstrate that physical locations, equipment, media and facilities supporting the ISMS scope are identified and protected according to information-security risk.

## 2. Required evidence

### Site register
- office/data/hosting locations;
- responsible owner;
- systems/assets present;
- criticality;
- physical security boundary;
- environmental risks.

### Access control
- authorized personnel list;
- access mechanism;
- access review;
- visitor procedure/log;
- access removal evidence.

### Equipment and media
- equipment inventory;
- secure placement/protection;
- removable-media handling;
- disposal/reuse process;
- backup-media protection.

### Environmental protection
- power/environment controls as applicable;
- fire/water/temperature risks;
- continuity dependencies;
- periodic inspection records.

## 3. Acceptance test

Move from **MISSING** to **AVAILABLE** only after the applicable physical locations are identified, assessed and the required protective measures are evidenced and reviewed.

## 4. Evidence protection

Exact addresses, access arrangements, security-system details and sensitive facility information should be kept in a controlled evidence repository rather than published in this repository.
