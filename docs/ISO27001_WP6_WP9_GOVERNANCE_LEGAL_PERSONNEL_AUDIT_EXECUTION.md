## WP6 — Governance, legal, regulatory and records

Priority controls include A.5.1, A.5.4, A.5.5, A.5.6, A.5.7, A.5.8, A.5.31–A.5.37.

Required evidence:

1. Approved information-security policy set.
2. Defined roles, authorities and review responsibilities.
3. Contact register for authorities and relevant professional/special-interest groups.
4. Threat/intelligence monitoring where applicable.
5. Security requirements embedded in projects and change processes.
6. Legal, regulatory, contractual and privacy requirements register.
7. Intellectual-property ownership and licensing records.
8. Information-retention and disposal requirements.
9. Evidence/records protection and integrity rules.
10. Periodic policy review and change history.

## WP7 — Personnel security

A.6.1–A.6.8 are organizational controls and require actual personnel evidence.

Required evidence:

- role descriptions;
- confidentiality/NDA commitments;
- screening where legally and operationally applicable;
- onboarding and security awareness;
- acceptable-use requirements;
- disciplinary process;
- role-change access review;
- termination/offboarding and access revocation.

No personal sensitive data should be committed to the public repository. Controlled records must remain in the appropriate restricted evidence location.

## WP8 — Physical security

A.7.1–A.7.14 require physical-site evidence, not source-code evidence.

Required evidence:

- site and secure-area register;
- physical access authorization;
- visitor management;
- equipment/media protection;
- environmental and utility risk assessment;
- secure disposal/media handling;
- maintenance records;
- monitoring where required.

## WP9 — Internal audit and corrective action

Before G7 can close:

1. approve audit scope and criteria;
2. confirm auditor independence;
3. select representative samples;
4. inspect objective evidence;
5. test operating effectiveness;
6. record findings and severity;
7. assign corrective actions;
8. verify effectiveness;
9. issue internal-audit report.

Corrective action follows:

`Identify → Contain → Cause → Correction → Owner → Deadline → Implement → Verify → Close → Lessons`

## G8 — Management review

Management review must consider, as applicable:

- prior actions;
- changes in internal/external context;
- interested-party requirements;
- information-security objectives;
- risk-treatment results;
- audit findings;
- incidents;
- supplier performance;
- resource adequacy;
- improvement opportunities.

The output must contain dated decisions and assigned actions.

## G9 — Independent assessment

Independent re-performance or certification assessment must be performed by a suitably independent competent party. Repository documentation may prepare the evidence set but cannot substitute for the independent assessment.

## Final evidence rule

No control is declared GREEN solely because a policy or template exists.

Required chain:

`Requirement → Owner → Implemented operation → Objective evidence → Review → Decision → Retention`
