# DEE Architecture Baseline v1 — Accepted Structure

The accepted structural model is:

`NEF + GerChain → Core Adapter → EXIM Port → Connector Adapter → I2B Multi-Connector Gateway → Төр / Компани / Хувь хүн`

SHUUD / SHIID is one replaceable business application prototype connected through the Company side. It is not a core infrastructure layer.

This file is an explicit architecture acceptance marker. It does not introduce identity/authorization Phase 2 changes.
