# NEF–G-3–GerChain — Supplier Security Requirements

**Status:** Controlled requirements — evidence pending

## 1. Purpose

Define the minimum supplier-security evidence for services, software, infrastructure and professional support within the ISMS scope.

## 2. Supplier register

Each relevant supplier shall be recorded with:

- supplier name and service;
- business owner;
- information/system accessed;
- information classification;
- access level;
- contract status;
- security requirements;
- review frequency;
- termination/offboarding requirement.

## 3. Due diligence

Risk-based supplier assessment shall consider:

- information-security capability;
- access to confidential information;
- hosting/location implications;
- subcontractors;
- incident notification;
- business continuity;
- data protection;
- legal/regulatory obligations;
- secure termination and return/deletion of information.

## 4. Contract requirements

Relevant contracts should address security responsibilities, access control, confidentiality, incident notification, data handling, continuity, audit/cooperation and termination requirements as appropriate to risk.

## 5. Evidence

Required evidence may include approved supplier register, assessment records, contracts, security questionnaires, review minutes, incident records and offboarding confirmation.

## 6. Gate

**Supplier security: MISSING — supplier inventory, risk assessment and contractual evidence required.**
