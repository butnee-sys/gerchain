# SHUUD Sandbox Day-0 Package

The Day-0 sandbox package consists of:

1. `docs/shuud-sandbox-day0.md` — 90-day sandbox baseline and acceptance gate.
2. `docs/shuud-sandbox-deployment-checklist.md` — environment and deployment checklist.
3. `docs/shuud-sandbox-incident-scenarios.md` — controlled scenario matrix.
4. `docs/shuud-sandbox-day0-roles.md` — Day-0 RACI.
5. `docs/shuud-sandbox-day0-runbook.md` — operational runbook.

These documents are preparation artifacts. Actual participant names, endpoints, credentials, insurance rules, and production authorization must be supplied through the sandbox governance process before live use.
