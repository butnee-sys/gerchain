# NEF–G-3–GerChain — Physical Security Requirements

**Status:** Controlled requirements — site evidence pending

## 1. Scope

Physical security shall cover locations and facilities where scoped information, systems, equipment, backups or administrative activities are handled.

## 2. Required assessment

The organization shall identify, as applicable:

- relevant sites and rooms;
- physical access controls;
- visitor controls;
- equipment protection;
- environmental risks;
- power/connectivity resilience;
- media storage and disposal;
- monitoring where appropriate;
- responsibilities for leased/third-party facilities.

## 3. Evidence

Objective evidence may include site register, access authorization, visitor records, facility/security procedures, equipment inventory, environmental safeguards, photographs where appropriate, supplier attestations and inspection records.

Sensitive physical-security details shall not be publicly exposed if doing so would weaken security.

## 4. Technical boundary

GitHub branch protection and software controls do not constitute physical-security evidence.
