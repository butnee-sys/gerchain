## W3 invariants demonstrated

- Single canonical authority for the schema identity.
- No lost authoritative upgrade.
- No split-brain committed version.
- Exact predecessor enforcement.
- Atomic authoritative transition at the PostgreSQL transaction boundary.
- Same upgrade identity is idempotent when retried with the same transition.
- Distinct incompatible concurrent upgrades cannot both commit from one predecessor.
- Failed migration preserves the predecessor authority.
- Readers observe committed schema state only.

## Deterministic / independent result

Independent PostgreSQL re-performance used isolated PostgreSQL tables and did not import GerChain production persistence code. It reproduced:

- distinct concurrent upgrades -> one authoritative successor;
- same upgrade retry -> idempotent;
- rollback -> predecessor preserved.

## Boundary / non-claim

This closure does **not** establish that a complete production DDL migration executor is integrated with this authority layer. The migration executor remains a separately declared architectural concern. Therefore W3 GREEN is bounded to the schema/version authority and concurrency transition contract described above.

This closure does not establish final CORE GREEN or CORE LOCK.
