# Security Policy

## Scope

This security policy applies to the GerChain repository and its published software artifacts. GerChain CORE is the protected technical infrastructure scope.

SHUUD application behavior is outside the CORE security-assurance scope unless explicitly included in a future assessment.

## Reporting a vulnerability

Please do not disclose suspected security vulnerabilities in public issues.

Report security vulnerabilities privately to the repository maintainers through the security contact configured for this repository. Include, where safely possible:

- affected component or path;
- vulnerability description;
- reproducible steps or proof of concept;
- potential impact;
- affected version or commit;
- suggested mitigation, if known.

Do not include passwords, private keys, API tokens, production credentials, personal data, or other secrets in a report or repository issue.

## Response

Reports are triaged, recorded, assessed for severity and impact, contained where necessary, remediated, verified, and closed with an appropriate record.

Security fixes must follow the repository's protected-branch and review requirements.

## Disclosure

Public disclosure should occur only after the maintainers have assessed the issue and coordinated an appropriate remediation and disclosure timeline.

## Assurance status

OpenSSF Scorecard and other security assessments are evidence of technical security posture and do not constitute ISO/IEC 27001 certification or an independent audit opinion.
