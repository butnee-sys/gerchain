# SHUUD — Minor Incident Rapid Resolution

**Зорилго: “2 минутанд замаа чөлөөл.”**

SHUUD нь зам тээврийн хөнгөн осол, эвдрэл, зам хаасан саад зэрэг хүний амь насанд шууд аюул багатай тохиолдлыг хурдан мэдээлэх, нотлох, зохицуулах, замыг чөлөөлөх, даатгалын процессыг эхлүүлэх үйл ажиллагааны дэд бүтэц юм.

## Архитектурын хил

```text
SHUUD APP
   ↓
SHUUD INCIDENT ENGINE
   ↓
GERCHAIN EVIDENCE
   ↓
NEF / ESCROW / CLAIM
```

SHUUD нь GerChain-ийн үндсэн зарчим, нотлох баримтын бүрэн бүтэн байдал, төлөвийн тодорхой шилжилт, аудитын мөрийг тойрч гарахгүй. Харин GerChain-ийг замын ослын бүх хэрэглэгчийн интерфейсээр дүүргэхгүй; SHUUD нь хэрэглээний давхарга байна.

## MVP төлөвийн дараалал

```text
REPORTED
   ↓
VERIFIED
   ↓
DISPATCHED
   ↓
ON_SCENE
   ↓
CLEARING
   ↓
CLEARED
   ↓
CLAIM_OPENED
   ↓
CLOSED
```

Хэрэв тохиолдол нь хөнгөн ослын шалгуурт нийцэхгүй бол:

```text
REPORTED → ESCALATED
```

## 2 минутын зорилт

- **T0** — мэдээлэл бүртгэгдэв
- **T+** — тохиолдлын ангилал баталгаажна
- **T+** — оролцогч/зохицуулагчид холбогдоно
- **T+120 сек** — боломжтой хөнгөн тохиолдолд зорчих хэсгийг чөлөөлсөн байна

2 минут нь зөвхөн дэлгэцийн тоолуур биш; үйл ажиллагааны үндсэн хэмжүүр байна.

## Нотлох баримтын үндсэн талбар

- incident_id
- event_id
- timestamp
- GPS байршил
- мэдээлэгч/оролцогчийн таних мэдээлэл
- тээврийн хэрэгслийн мэдээлэл
- тохиолдлын төрөл
- зураг/бичлэгийн хэш
- төлөвийн шилжилт
- зам чөлөөлсөн баталгаа
- даатгалын нэхэмжлэлтэй холбох түлхүүр
